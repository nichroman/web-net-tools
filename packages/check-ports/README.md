# check-ports

Веб-версия сканера TCP-портов. Повторяет функциональность PowerShell-скриптов
`PortScaner\port_scanner.ps1` (порт 80) и `PortScaner\port443_scanner.ps1` (порт 443),
но работает через браузер и Node.js-бэкенд.

Формат результата совпадает с PS-версией: `Hostname,Port,Status,ScanTime`
(статусы `Open` / `Closed/Unreachable`), что позволяет использовать уже существующие
файлы результатов и списки узлов проекта PortScaner.

## Возможности

- Проверка отдельного узла вручную: ввод IP-адреса или имени хоста (принимаются также URL и `host:порт`),
  результат добавляется в таблицу, повторная проверка того же узла обновляет строку (дубликатов нет).
- Выбор набора данных из файлов проекта (`*.csv`, `*.txt`) или загрузка локального файла.
- Поддерживаемые форматы: TXT (адрес в строке), CSV `Address;Comment`,
  а также CSV-результаты (`Hostname,Port,Status,ScanTime`) — их можно использовать как новый список узлов.
- Произвольный список портов: `80`, `443`, `80,443`, `1-1024` (до 256 портов).
- Настраиваемый таймаут подключения 100-10000 мс (по умолчанию 1000 мс, как в PS-версии).
- Прогресс-бар, кнопка остановки, статистика и таблица результатов с фильтром.
- Экспорт: CSV в формате PS-версии, списки адресов `Port<порты>Opened.txt` / `Port<порты>Closed.txt`.
- Сохранение CSV-результата в каталоге проекта (аналог `Out-File` из PowerShell).

## Запуск

```
npm install
npm start
```

или запустите `npm_start.bat` (открывает браузер на http://localhost:3001).

Порт сервера изменяется переменной окружения `PORT` (по умолчанию 3001),
интерфейс прослушивания — переменной `HOST` (по умолчанию `127.0.0.1`; значение
`0.0.0.0` открывает доступ с других компьютеров и требует правила брандмауэра).

## API

| Метод | Адрес | Назначение |
| --- | --- | --- |
| GET | `/api/health` | состояние сервера |
| GET | `/api/datasets` | список наборов данных (CSV/TXT в каталоге проекта) |
| GET | `/api/dataset/:filename` | содержимое набора данных |
| GET | `/api/scan?host=&ports=&timeout=` | сканирование одного узла |
| POST | `/api/scan-batch` | сканирование нескольких узлов `{ "hosts": [...], "ports": "80,443", "timeout": 1000 }` |
| POST | `/api/save-results` | сохранение CSV `{ "filename": "scan_results.csv", "csv": "..." }` |
| POST | `/api/scan-and-save` | сканирование списка узлов с сохранением CSV в файл |

## Состав

- `server.js` — Express-сервер (TCP-сканирование через `net.Socket`, API, сохранение файлов).
- `index.html` — интерфейс (ES5/XMLHttpRequest, совместим с IE11).
- `hosts.csv`, `80Port_test_hosts.txt` — примеры списков узлов.
- `monkey.png` — логотип в шапке (как в WEB_check_nodes_v0.0.4).

## Развёртывание для всех пользователей Windows

Общая установка с ярлыками на общем рабочем столе выполняется отдельным проектом
`..\Web_NetTools_v0.0.2` (запуск `install.bat` от администратора):

- программы копируются в `C:\Tools\WebNetTools` (`check-nodes`, `check-ports`, `launcher`, `logs`);
- каталог получает права «Изменение» для группы «Пользователи» — именно поэтому
  сохранение результатов сканирования (`/api/save-results`, `/api/scan-and-save`)
  работает у обычного пользователя без прав администратора;
- на общем рабочем столе и в общем меню «Пуск» создаются ярлыки, которые запускают
  сервер скрыто (без окна консоли) и открывают браузер;
- сервер слушает `127.0.0.1`, поэтому запрос брандмауэра Windows не появляется;
- один экземпляр программы на компьютер: повторный щелчок ярлыка только открывает браузер;
- списки узлов и результаты сканирования общие для всех пользователей компьютера.
