# web-net-tools

Дистрибутив сетевых веб-утилит для Windows: проверка доступности узлов (ICMP `ping`)
и сканирование TCP-портов. Установка выполняется один раз на компьютер, ярлыки
создаются на общем рабочем столе и доступны **всем пользователям** ОС.

## Состав репозитория

```
web-net-tools\
└── Web_NetTools_v0.0.2\              дистрибутив установки (самодостаточный)
    ├── install.bat / install.ps1     установка (права администратора запрашиваются сами)
    ├── uninstall.bat / uninstall.ps1 удаление
    ├── update-packages.ps1           обновление приложений в packages
    ├── launcher\                     запуск и остановка серверов (PowerShell + резервный VBS)
    ├── packages\
    │   ├── check-nodes\              WEB_check_nodes v0.0.4 — проверка узлов, порт 3000
    │   ├── check-ports\              WEB_check_ports v0.0.1 — сканер TCP-портов, порт 3001
    │   └── VERSION.txt               что и когда скопировано
    └── README.md                     подробная документация дистрибутива
```

Утилиты лежат внутри `packages` вместе с зависимостями (`node_modules`: express, cors),
поэтому установка не требует npm и доступа в интернет — нужен только Node.js.

## Быстрая установка

1. Скачайте репозиторий (Code → Download ZIP) или клонируйте:
   `git clone https://github.com/nichroman/web-net-tools.git`
2. Установите Node.js 14+ (для Windows 7 x86 — `node-v14.21.3-x86.msi`).
3. Запустите `Web_NetTools_v0.0.2\install.bat` и подтвердите запрос UAC.
4. На общем рабочем столе появятся ярлыки:
   * «Проверка узлов (Web_NetTools)» → http://localhost:3000
   * «Проверка портов (Web_NetTools)» → http://localhost:3001

Ярлык запускает сервер скрыто, проверяет, не запущен ли он уже, и открывает браузер.
Списки узлов и результаты сканирования — в `C:\Tools\WebNetTools\check-nodes` и
`...\check-ports`, журналы — в `...\logs`. Удаление — `uninstall.bat`.

Подробности: `Web_NetTools_v0.0.2\README.md` и `Web_NetTools_v0.0.2\packages\README.txt`.

## Отдельные репозитории утилит

* проверка узлов — https://github.com/nichroman/check-nodes
* проверка портов — https://github.com/nichroman/check-ports
* вариант для Windows 7 x86 — https://github.com/nichroman/check-nodes-win7

В этом репозитории утилиты поставляются в составе дистрибутива
(`Web_NetTools_v0.0.2\packages`); их исходные проекты развиваются в отдельных
репозиториях, а копии в дистрибутиве обновляются скриптом `update-packages.ps1`.

## Что исправлено и добавлено

* **Проверка узлов**: исправлен разбор вывода `ping`. Windows отдаёт текст в кодировке
  консоли (в русской Windows — CP866), а Node.js читал поток как UTF-8, из-за чего
  все узлы получали статус «Недоступен». Теперь поток декодируется нужной кодировкой,
  а ответ дополнительно распознаётся по языконезависимому признаку `TTL=`.
* **Приложения включены в дистрибутив**: `packages\check-nodes` и `packages\check-ports`
  содержат `server.js`, интерфейс, наборы данных и `node_modules`; установщик находит
  их автоматически (соседние каталоги не нужны), обновление — `update-packages.ps1`.
* **Лаунчер**: сам задаёт `PORT` и `HOST` для запускаемого сервера (глобальные
  переменные окружения больше не мешают), быстро проверяет готовность, сразу сообщает
  о падении сервера, останавливает «осиротевшие» процессы, поддерживает `-NoDialogs`
  для автоматического запуска.
* **Остановка серверов**: `stop-webnettools.ps1 -Ports 3000,3001 -AppRoot "C:\Tools\WebNetTools"`
  принимает список портов и не трогает процессы других установок Web_NetTools.
* **Установщик**: надёжный поиск каталогов утилит (параметр → `packages` → соседние
  каталоги, включая вложенные → общие папки), понятные ошибки со списком проверенных
  мест, права «Изменение» для группы «Пользователи», резервные VBScript-ярлыки,
  инструкция `INSTALL.txt` в каталоге установки.

## Требования

* Windows 7 SP1 / 10 / 11 (x86 и x64)
* Node.js 14+ (для Windows 7 x86 — Node.js 14.21.3 x86)
* Права администратора — только для установки и удаления

## Служебное

* Порты по умолчанию: 3000 (проверка узлов), 3001 (проверка портов); меняются
  параметром `-Port` в сценарии ярлыка, адрес — параметром `-BindAddress`.
* Каталог установки по умолчанию: `C:\Tools\WebNetTools`
  (`install.bat -InstallDir "D:\Tools\WebNetTools"`).
* Один экземпляр утилиты на компьютер: повторный щелчок ярлыка только открывает браузер.
* Данные (списки узлов и результаты сканирования) общие для всех пользователей компьютера.
