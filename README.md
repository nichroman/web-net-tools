# web-net-tools

Набор сетевых веб-утилит для Windows и средства их развёртывания: проверка
доступности узлов (`ping`) и сканирование TCP-портов. Утилиты работают как локальные
веб-приложения (Node.js + браузер) и устанавливаются один раз на компьютер так, что
ярлыки видны **всем пользователям** на общем рабочем столе.

## Состав репозитория

| Каталог | Назначение |
| --- | --- |
| `Web_NetTools_v0.0.1` | установщик и лаунчер: копирует утилиты в `C:\Tools\WebNetTools`, выдаёт права «Изменение» группе «Пользователи», создаёт ярлыки на общем рабочем столе и в меню «Пуск» |
| `WEB_check_nodes_v0.0.4` | проверка доступности узлов (ICMP ping), порт **3000** |
| `WEB_check_ports_v0.0.1` | сканер TCP-портов, порт **3001** |
| `WEB_check_nodes_v0.0.4_win7x86` | та же проверка узлов для Windows 7 x86 (Node.js 14.21.3 x86) |

## Быстрая установка

1. Скачайте репозиторий (Code → Download ZIP) или клонируйте:
   `git clone https://github.com/nichroman/web-net-tools.git`
2. Установите **Node.js 14+** (для Windows 7 x86 — `node-v14.21.3-x86.msi`).
3. Запустите **`Web_NetTools_v0.0.1\install.bat`** и подтвердите запрос UAC.
   Установщик сам находит каталоги утилит рядом с собой; при необходимости пути
   задаются явно: `install.bat -NodesSource "путь" -PortsSource "путь"`.
4. На общем рабочем столе появятся ярлыки:
   * «Проверка узлов (Web_NetTools)» → http://localhost:3000
   * «Проверка портов (Web_NetTools)» → http://localhost:3001

Ярлык запускает сервер скрыто (без окна консоли), проверяет, не запущен ли он уже,
и открывает браузер. Списки узлов и результаты сканирования находятся в
`C:\Tools\WebNetTools\check-nodes` и `...\check-ports`, журналы — в `...\logs`.

Удаление: `Web_NetTools_v0.0.1\uninstall.bat` (права администратора).

## Что исправлено в этой версии

* **Проверка узлов работала неверно**: Windows отдаёт вывод `ping` в кодировке
  консоли (в русской Windows — CP866), а Node.js читал поток как UTF-8, из-за чего
  все узлы получали статус «Недоступен». Теперь поток декодируется в нужной
  кодировке (UTF-8 / CP866 / CP1251 / CP437), а ответ дополнительно распознаётся по
  языконезависимому признаку `TTL=`.
* Обе утилиты получили эндпоинт `/api/health`, читают `PORT`/`HOST` из переменных
  окружения и слушают только `127.0.0.1` — запрос брандмауэра Windows не появляется,
  доступ из сети закрыт.
* Лаунчер: быстрая проверка готовности сервера (через список слушающих портов),
  остановка «осиротевших» процессов при неудачном старте, ключ `-NoDialogs` для
  автоматического запуска, понятные сообщения (в том числе о глобальных переменных
  `PORT`/`HOST`).
* Установщик: надёжный поиск каталогов утилит (параметр → `packages` → соседние
  каталоги, включая вложенные → общие папки), понятные ошибки с перечнем проверенных
  мест, права «Изменение» для группы «Пользователи», резервные VBScript-ярлыки.
* Лаунчер и установщик совместимы с Windows PowerShell 2.0 (Windows 7) и PowerShell 7.

Подробности — в README соответствующих каталогов:
`Web_NetTools_v0.0.1\README.md`, `WEB_check_nodes_v0.0.4\README.md`,
`WEB_check_ports_v0.0.1\README.md`.

## Требования

* Windows 7 SP1 / 10 / 11 (x86 и x64)
* Node.js 14+ (для Windows 7 x86 — Node.js 14.21.3 x86)
* Права администратора — только для установки и удаления, пользователям не нужны

## Служебное

* Порты по умолчанию: 3000 (узлы), 3001 (порты); переопределяются переменной `PORT`.
* Каталог установки по умолчанию: `C:\Tools\WebNetTools`
  (можно изменить: `install.bat -InstallDir "D:\Tools\WebNetTools"`).
* Один экземпляр утилиты на компьютер: повторный щелчок ярлыка только открывает браузер.
* Данные (списки узлов и результаты) общие для всех пользователей компьютера.
