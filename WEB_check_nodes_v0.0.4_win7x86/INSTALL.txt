========================================
Установка и запуск для Windows 7 x86
========================================

ТРЕБОВАНИЯ:
- Windows 7 SP1 (32-bit / x86)
- Node.js 14.x (последняя версия, поддерживающая Win7)

УСТАНОВКА NODE.JS 14.x:
1. Скачайте Node.js 14.21.3 (LTS) для Windows x86:
   https://nodejs.org/dist/v14.21.3/node-v14.21.3-x86.msi
   
   Или прямая ссылка:
   https://nodejs.org/dist/v14.21.3/node-v14.21.3-x86.msi

2. Установите Node.js (стандартная установка)

3. Проверьте установку:
   node --version
   npm --version

ЗАПУСК ПРИЛОЖЕНИЯ:
1. Скопируйте папку WEB_check_nodes_win7 на компьютер с Windows 7
2. Запустите run.bat (двойной клик)
3. Откройте браузер: http://localhost:3000

АЛЬТЕРНАТИВНЫЙ ЗАПУСК:
1. Откройте командную строку (cmd.exe)
2. Перейдите в папку: cd /d "путь\к\WEB_check_nodes_win7"
3. Запустите: npm start

ПРИМЕЧАНИЯ:
- Express 4.18.2 и CORS 2.8.5 совместимы с Node.js 14.x
- JavaScript фронтенда использует ES5 (совместим со старыми браузерами)
- Для остановки сервера нажмите Ctrl+C
